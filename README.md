# Theo — большая коллекция плагинов для TheoTown

Здесь мы собираем крупный пак плагинов для [TheoTown](https://www.theotown.com/).
Первый модуль пака — **дороги**: 8 типов дорог, дорожная разметка и уличные
фонари. Вся графика генерируется кодом (никаких заимствованных картинок),
поэтому пак легко расширять и перекрашивать.

## Что уже готово (Пак дорог, v1)

**Дороги** (категория «Дороги Theo» → «Дороги»):

| Дорога | Цена | Скорость | Уровень | Особенности |
|---|---|---|---|---|
| Гравийная дорога | 15 | 1.2 | 0 | без разметки, обочина из земли |
| Загородная дорога | 90 | 2.0 | 1 | обочина, прерывистая осевая |
| Городская улица | 170 | 2.3 | 1 | тротуар, прерывистая осевая |
| Двухполосная улица | 240 | 2.5 | 1 | краевые линии + осевая |
| Проспект | 380 | 3.0 | 2 | жёлтая осевая, белые краевые |
| Проспект с разделителями | 520 | 3.2 | 2 | по две полосы в каждую сторону |
| Скоростная магистраль | 900 | 4.5 | 3 | только легковые и автобусы |
| Автомагистраль (односторонняя) | 1400 | 5.5 | 3 | отбойники, стрелки направления |

**Разметка и фонари** (категория «Разметка и фонари»):

* Пешеходный переход («зебра») — по обеим ориентациям дороги;
* Стоп-линия;
* «Лежачий полицейский» (скорость ×0.6);
* Уличный фонарь — ставится линией вдоль дороги, светит над машинами.

## Как собрать

Нужен Python 3.10+ и библиотеки `pillow` и `numpy`:

```bash
pip install pillow numpy
python3 tools/build_pack.py --preview
```

Результат:

```
dist/TheoRoadsPack/                 # папка плагина
dist/theo-roads-pack-v1.0.0.zip     # готовый архив для установки
dist/preview_*.png                  # картинки для описания/форума
```

## Как установить в игру

Готовые файлы лежат в `dist/`:

* `TheoRoadsPack-v1.0.0.plugin` — **самый простой вариант**: кинуть файл в
  папку плагинов, распаковывать не нужно;
* `theo-roads-pack-v1.0.0.zip` — то же самое в виде архива;
* `TheoRoadsPack/` — готовая распакованная папка плагина;
* `КАК-УСТАНОВИТЬ.txt` — инструкция рядом с файлами.

### Телефон (Android) — через файловый менеджер игры

1. Скачайте `TheoRoadsPack-v1.0.0.plugin` в «Загрузки».
2. Запустите TheoTown и выйдите из города в вид региона.
3. Меню → **Файловый менеджер** (File manager) → откройте папку `plugins`.
4. **Импорт файла(ов)** → выберите скачанный файл.
5. Полностью закройте игру (смахните из списка недавних) и запустите снова.

Так не нужно трогать системную папку `Android/data`, в которую на Android 11+
обычный проводник не пускает.

### Телефон (Android) — вручную, если хочется

Папка плагинов: `Android/data/info.flowersoft.theotown.theotown/files/plugins`
(на Android 10 и ниже — `Internal Storage/TheoTown/plugins`). На Android 11+
нужен файловый менеджер с доступом к `Android/data` — ZArchiver, MiXplorer,
Files by Google: при первом заходе приложение спросит разрешение
«Use this folder». Положите туда `.plugin`/`.zip` (игра умеет читать архивы
сама) либо распакуйте архив — получится папка `TheoRoadsPack`.

### Компьютер

Windows: `C:/Users/<имя>/TheoTown/plugins`, Linux: `~/TheoTown/plugins`,
macOS: `~/TheoTown/plugins`. Скопируйте туда файл `.plugin` или
распакованную папку `TheoRoadsPack`.

После установки: Настройки → Плагины — в списке появится «Theo Roads Pack»,
а в городе новые дороги будут в разделе транспорта, категория **Theo Roads**.
Не удаляйте плагин, если уже сохранили город с этими дорогами.

Плагин ставится и в одиночную игру, и в мультиплеер (`"multiplayer": true`
в манифесте). Для городов, сохранённых с этим паком, не удаляйте папку
плагина: id объектов используются при загрузке сохранений.

## Структура репозитория

```
tools/
  build_pack.py            # точка входа: собрать пак и превью
  theo_pack/
    iso.py                 # геометрия дорог: изометрия, кадры соединений
    art.py                 # палитра и примитивы пиксель-арта
    roads.py               # генерация спрайтов дорог, светофоров, стрелок
    decos.py               # генерация разметки и фонарей
    plugins.py             # JSON-описания, манифест, упаковка, валидатор
    preview.py             # демонстрационные сцены
dist/                      # результат сборки (артефакты)
```
