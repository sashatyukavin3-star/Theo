# Theo — большая коллекция плагинов для TheoTown

Здесь мы собираем крупный пак плагинов для [TheoTown](https://www.theotown.com/).
Первый модуль — **дороги**: 8 типов, разметка и фонари. Второй модуль —
**жилые здания РФ**, начальный сектор (жилой уровень 1): деревянный дом,
кирпичная дача и пятиэтажный панельный дом. Вся графика создаётся кодом как
пиксель-арт на сетке TheoTown, без заимствованных игровых картинок.

## Что уже готово (Пак дорог, v1)

**Дороги** (категория «Дороги Theo» → «Дороги»):

| Дорога | Цена | Скорость | Уровень | Особенности |
|---|---|---|---|---|
| Гравийная дорога | 15 | 1.2 | 0 | без разметки, обочина из земли |
| Загородная дорога | 90 | 2.0 | 1 | обочина, прерывистая осевая |
| Городская улица | 170 | 2.3 | 1 | тротуар, прерывистая осевая |
| Двухполосная улица | 240 | 2.5 | 1 | краевые линии + осевая |
| Проспект | 380 | 3.0 | 2 | жёлтая осевая, белые краевые |
| Проспект с разделителями | 520 | 3.2 | 2 | по две полосы в каждую сторону |
| Скоростная магистраль | 900 | 4.5 | 3 | только легковые и автобусы |
| Автомагистраль (односторонняя) | 1400 | 5.5 | 3 | отбойники, стрелки направления |

**Разметка и фонари** (категория «Разметка и фонари»):

* Пешеходный переход («зебра») — по обеим ориентациям дороги;
* Стоп-линия;
* «Лежачий полицейский» (скорость ×0.6);
* Уличный фонарь — ставится линией вдоль дороги, светит над машинами.

## Жилые здания РФ — начальный сектор

Первый набор содержит три здания уровня 1:

| Здание | Пятно застройки | Образ |
|---|---:|---|
| Деревянный дом в селе | 1×1 | тёплые брёвна, синяя металлическая крыша, дорожка |
| Кирпичная дача | 1×1 | кирпичный фасад, красная двускатная крыша |
| Пятиэтажный панельный дом | 2×2 | советская панельная застройка, ритм окон и плоская крыша |

Рисунки — собственные процедурные спрайты PNG с прозрачностью. Скрипт
проверяет JSON, манифест, размеры кадров и уникальность ID перед упаковкой.

## Как собрать

Нужен Python 3.10+ и зависимости из `requirements.txt` (Pillow и NumPy).
Рекомендуемый запуск в изолированном окружении:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python tools/build_pack.py --preview
.venv/bin/python tools/build_residential.py
```

В Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

Результаты:

```
dist/TheoRoadsPack/                                  # папка дорожного плагина
dist/theo-roads-pack-v1.0.0.zip                      # архив дорог
dist/TheoRussianHomesStarter/                        # папка жилого плагина
dist/TheoRussianHomesStarter-v1.0.0.plugin           # готовый жилой плагин
dist/theo-russian-homes-starter-v1.0.0.zip           # тот же пакет в ZIP
dist/preview_*.png                                   # превью модулей
```

## Как установить в игру

Готовые файлы лежат в `dist/`:

* `TheoRoadsPack-v1.0.0.plugin` — пак дорог;
* `TheoRussianHomesStarter-v1.0.0.plugin` — стартовый жилой сектор РФ;
* `.plugin` можно положить в папку плагинов или импортировать через файловый
  менеджер игры — распаковывать не нужно;
* ZIP-файлы и распакованные папки модулей также лежат в `dist/`;
* `КАК-УСТАНОВИТЬ.txt` и `КАК-УСТАНОВИТЬ-ЖИЛЬЁ.txt` — инструкции.

### Телефон (Android) — через файловый менеджер игры

1. Скачайте `TheoRoadsPack-v1.0.0.plugin` или
   `TheoRussianHomesStarter-v1.0.0.plugin` в «Загрузки».
2. Запустите TheoTown и выйдите из города в вид региона.
3. Меню → **Файловый менеджер** (File manager) → откройте папку `plugins`.
4. **Импорт файла(ов)** → выберите скачанный файл.
5. Полностью закройте игру (смахните из списка недавних) и запустите снова.

Так не нужно трогать системную папку `Android/data`, в которую на Android 11+
обычный проводник не пускает.

### Телефон (Android) — вручную, если хочется

Папка плагинов: `Android/data/info.flowersoft.theotown.theotown/files/plugins`
(на Android 10 и ниже — `Internal Storage/TheoTown/plugins`). На Android 11+
нужен файловый менеджер с доступом к `Android/data` — ZArchiver, MiXplorer,
Files by Google: при первом заходе приложение спросит разрешение
«Use this folder». Положите туда `.plugin`/`.zip` (игра умеет читать архивы
сама) либо распакуйте архив — получится папка `TheoRoadsPack` или
`TheoRussianHomesStarter`.

### Компьютер

Windows: `C:/Users/<имя>/TheoTown/plugins`, Linux: `~/TheoTown/plugins`,
macOS: `~/TheoTown/plugins`. Скопируйте туда файл `.plugin` или
распакованную папку нужного модуля.

После установки: Настройки → Плагины — появится соответствующий пак.
Дороги находятся в разделе транспорта, а жилые здания уровня 1 появляются
при застройке жилой зоны. Не удаляйте плагин, если город уже сохранён
с его объектами.

Плагин ставится и в одиночную игру, и в мультиплеер (`"multiplayer": true`
в манифесте). Для городов, сохранённых с этим паком, не удаляйте папку
плагина: id объектов используются при загрузке сохранений.

## Структура репозитория

```
requirements.txt           # зависимости генераторов (Pillow, NumPy)
tools/
  build_pack.py            # собрать дорожный пак и превью
  build_residential.py     # собрать жилой сектор РФ и проверить его
  theo_pack/
    iso.py                 # геометрия дорожных кадров
    art.py                 # палитра и базовые операции пиксель-арта
    roads.py               # процедурная графика дорог
    decos.py               # разметка и фонари
    plugins.py             # JSON, манифест, валидация дорожного пака
    residential.py         # спрайты, JSON и проверки жилых зданий
dist/                      # собранные плагины и превью
```
