# Генератор плагинов TheoTown (`tools/`)

Локальная Python-сборка для двух модулей: дорожного пака и российских жилых
зданий. PNG и JSON генерируются из исходного кода; в плагин не включаются
заимствованные игровые ассеты.

## Подготовка окружения

Нужен Python 3.10+. Зависимости перечислены в `requirements.txt`:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

В Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

## Сборка

```bash
.venv/bin/python tools/build_pack.py --preview
.venv/bin/python tools/build_residential.py
```

`build_residential.py` собирает в `dist/`:

* `TheoRussianHomesStarter/` — папку готового плагина;
* `TheoRussianHomesStarter-v1.0.0.plugin` и `theo-russian-homes-starter-v1.0.0.zip`;
* `preview_residential_ru.png` — увеличенное превью трёх спрайтов;
* `КАК-УСТАНОВИТЬ-ЖИЛЬЁ.txt` — краткую инструкцию.

Скрипт заменяет только собственную папку `TheoRussianHomesStarter`; остальные
артефакты `dist/`, включая дорожный пак, не трогает.

## Стартовый сектор жилых зданий РФ

Все три здания имеют `type: residential`, `level: 1` и собственные постоянные
ID. Это маленький деревянный дом 1×1, кирпичная дача 1×1 и пятиэтажный
панельный дом 2×2. Население и другие стандартные параметры жилых зданий игра
определяет автоматически.

Графика рисуется на изометрической сетке TheoTown 32×16. Для новых зданий
достаточно добавить описание в `STARTER_BUILDINGS` и функцию/вариант рендера в
`theo_pack/residential.py`. Текущий генератор проверяет:

* корректность JSON-массива и `plugin.manifest`;
* уникальность ID и тип/уровень зданий;
* ссылки на PNG, RGBA-режим, footprint и непустую альфа-маску.

Собранный `.plugin` — ZIP-архив с папкой пака внутри. Для правок существующих
зданий сохраняйте их ID: они используются в сохранённых городах.

## Дорожный пак

`build_pack.py` генерирует `TheoRoadsPack`, превью дорог и файл установки.
Геометрия дороги — 16 кадров 32×16, индекс кадра является битовой маской
подключённых соседних плиток; подробности — в `theo_pack/iso.py` и `theo_pack/roads.py`.
