# Генератор плагинов TheoTown (`tools/`)

Вся графика и JSON пака создаются кодом. Это позволяет быстро делать новые
варианты дорог (перекрасить покрытие, поменять ширину полос, добавить
разметку) и держать репозиторий с читаемыми исходниками вместо набора PNG.

## Быстрый старт

```bash
pip install pillow numpy
python3 tools/build_pack.py            # собрать пак
python3 tools/build_pack.py --preview  # + демонстрационные картинки
```

## Формат дороги TheoTown (что важно знать)

* Плитка — ромб 32x16 (вид 2:1). Спрайт дороги — **16 кадров 32x16**,
  индекс кадра = маска подключённых соседей:

  | сторона | бит | сосед | экран |
  |---|---|---|---|
  | SE | 1 | (i+1, j) | вниз-вправо |
  | NE | 2 | (i, j-1) | вверх-вправо |
  | NW | 4 | (i-1, j) | вверх-влево |
  | SW | 8 | (i, j+1) | вниз-влево |

  Кадр 0 — тупик, 5 — прямая вдоль оси s («вертикаль»), 10 — прямая вдоль
  оси t («горизонталь»), 15 — перекрёсток. Формат проверен на штатных
  дорогах игры (`content_road.json` + атлас `world_0_0.png`).
* Дорога шириной в 2 тайла (`"width": 2`) и односторонние дороги
  (`"one way": true`) требуют **64 кадра**: 4 копии листа 16 кадров
  (юго-восток, северо-восток, северо-запад, юго-запад) — в генераторе для
  этого используется `{"count": 16, "copies": 3}`.
* Разметка рисуется только на прямых кадрах (5 и 10), как в игре: на
  поворотах и стыках линии просто обрываются.
* Дорожные украшения — отдельный тип `road decoration`: наборы анимаций +
  таблица «кадр дороги → какие анимации показывать»
  (`frame animation indices`). Фонарь использует `animation fg`, чтобы
  рисоваться поверх машин.
* Тоннели: 4 кадра 16x19 с `handle y: 7` (см. `build_tunnel_frames`).
* Светофоры: 4 кадра 32x32 + фазы `green phase` / `yellow phase`.

## Как добавить новую дорогу

1. Опишите стиль в `theo_pack/roads.py: ROAD_STYLES`:
   ```python
   "myroad": dict(
       surface="asphalt",        # покрытие: gravel/asphalt/asphalt_warm/...
       hw=0.40,                  # половина ширины проезжей части (s/t)
       walk=0.07,                # тротуар по краям (0 — без тротуара)
       shoulder=0.0,             # обочина снаружи тротуара
       marks=[dict(offset=0.0, w=0.075, dash=0.26, period=0.50,
                   phase=-0.14, color="white")],
       tall=False, rail=False,   # True — спрайт 32x32 с отбойниками
   ),
   ```
2. Добавьте запись в `theo_pack/plugins.py: ROAD_DEFS` (id, цена, скорость,
   уровень, требования).
3. `python3 tools/build_pack.py --preview` — пак пересоберётся.

## Модули

* `iso.py` — геометрия: суперсэмпленная маска дорожного полотна (объединение
  полос вдоль направлений), скругления стыков, эрозия/дилатация,
  преобразование в пиксели.
* `art.py` — палитра, шум, упаковка кадров в спрайт-лист.
* `roads.py` — 16 кадров дороги, отбойники, светофоры, стрелки
  одностороннего движения, порталы тоннелей.
* `decos.py` — «зебра», стоп-линия, «лежачий полицейский», уличный фонарь.
* `plugins.py` — сборка JSON, манифест, `validate_pack()`, упаковка в zip.
* `preview.py` — мини-рендер изометрических сцен для README и форума.

## Проверки

`validate_pack()` (вызывается при сборке) проверяет: уникальность id,
наличие всех PNG, ссылки анимаций и категорий. Сборка предупреждает, если
что-то пропало — например, забыли картинку для дороги.
